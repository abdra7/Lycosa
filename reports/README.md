# Lycosa systems report

Two independent academic-style reports, English and Arabic, generated by Python.
Not affiliated with or endorsed by Harvard University. Author-date references,
numbered figures, requirements traceability and explicit evidence boundaries are used.

Run `python reports/build_reports.py` after installing `reportlab`, `arabic-reshaper`,
`python-bidi`, `networkx`, `pypdf`, and `Pillow`. Windows fonts are used by default.
Outputs go to `output/pdf/`; intermediate visual QA goes to `tmp/pdfs/`.
The diagrams are vector graphics created with ReportLab's graphics engine from
NetworkX graph models. They are not screenshots or AI-generated approximations.

## Verified edition

- Source implementation: `6064535` (18 September 2026 report snapshot).
- English: 35 pages; Arabic: 34 pages; six vector diagrams in each.
- All pages rendered with Poppler and inspected via contact sheets; diagrams and
  representative Arabic prose also inspected at page scale. Arabic shaping and
  pure-LTR identifiers/multiplicity notation are handled separately.
- Page-count, non-empty-page, font-resource and overflow assertions passed.
- Fresh engineering checks: 311 backend tests, 48 Agent tests, four Flutter
  provider-control tests. Historical live checks are explicitly dated in the PDFs.
- Build uses `reportlab`, `arabic-reshaper`, `python-bidi`, `networkx`, `pypdf`;
  optional QA uses `Pillow` and Poppler. Windows Georgia, Segoe UI and Arial fonts
  are embedded as subsets in the PDFs; the font files are not redistributed.
- To reproduce QA, render PDFs to `tmp/pdfs/en-01.png` and `ar-01.png` etc. with
  `pdftoppm -r 85 -png`, then run `python reports/qa_reports.py`.

The implementation push is not a deployment. Existing services need a separate
rebuild/restart to load changed source; the report does not claim current runtime
availability from a historical live test.
